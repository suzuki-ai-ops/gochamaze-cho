# ごちゃまぜ帳

## v3 の構成

GitHub Pages で静的 Web アプリを公開しています。Google ログインには Firebase Authentication、メモの同期には Cloud Firestore を使います。Firebase は Spark（無料）プランで運用します。

## データの置き場所

| データ | 保存先 |
| --- | --- |
| メモ（本文、タイトル、タグなど） | Cloud Firestore。ログインしたアカウントで端末間を同期します。 |
| 添付ファイルとカスタムカテゴリ | この端末のブラウザ内。端末間では同期されません。 |
| 旧バージョンのデータ | この端末のブラウザ内。Firestore へ取り込んだ後もバックアップとして残ります。 |

オンラインでアプリを開き、メモを同期しておくと、ログイン状態が保持されている同じブラウザで、オフラインでもキャッシュ済みのメモを表示できます。初回のログインとアプリのキャッシュには通信が必要です。ブラウザの設定などで Firestore の永続化が使えない場合は、メモリキャッシュで動作します。

## Firestore ルールを反映する

1. Firebase コンソールで本番の Firebase プロジェクトを開きます。
2. **Firestore Database** の **ルール** タブを開きます。
3. リポジトリの [firestore.rules](firestore.rules) の内容をすべてコピーし、コンソールのルールエディタに貼り付けます。
4. **公開** を押してルールを反映します。
